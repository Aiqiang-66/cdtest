## 二、功能详情

### 2.1 需求1：Core23 选项新增

海剧的所有素材报表、海剧所有任务列表，选项Core和投放Core，新增Core23选项。

**验证点：**
- 素材报表页面 Core 筛选下拉框中出现 Core23
- 任务列表页面 Core 筛选下拉框中出现 Core23
- 投放 Core 选项中包含 Core23

### 2.2 需求2：转Core素材新增"转为C23素材"

海剧素材报表，"转Core素材"功能新增"转为C23素材"。

**验证点：**
- 选中素材后点击"转Core素材"，下拉菜单中出现"转为C23素材"选项
- 点击"转为C23素材"后能正常执行转换

### 2.3 需求3：自动化视频混剪/原片延长/高光前置支持Core23

海剧自动化视频混剪、原片延长、高光前置，都要支持Core23。

**验证点：**
- 视频混剪页面 Core 选项中包含 Core23
- 选择 Core23 后页面联动配置正确
- 原片延长页面 Core 选项中包含 Core23
- 高光前置页面 Core 选项中包含 Core23

### 2.4 需求4：FB/TT媒体C1转C23

选择FB和TT媒体的有纯净版素材，再点"转Core素材"→"转为C23素材"：

| 源 | 目标 |
|----|------|
| FB 916的C1 | TT 916的C23 |
| FB 45的C1 | (找到FB对应916去转) → TT 916的C23 |
| TT 916的C1 | TT 916的C23 |

**验证点：**
- FB 916尺寸C1素材可转为TT 916的C23
- FB 45尺寸C1素材先找对应916，再转为TT 916的C23
- TT 916尺寸C1素材可转为TT 916的C23

### 2.5 需求5：烧录资源列表水印落地页加C23 + 自动化水印制作加C23

烧录资源列表的水印落地页加一个C23，自动化水印制作也需要加C23。
C23 TT小程序统一水印底图（仅需要916尺寸）：`916（无logo）.zip`

**验证点：**
- 烧录资源列表页面类型选择"落地页"后 Core 选项包含 C23
- 烧录资源列表页面类型选择"水印"后 Core 选项包含 C23
- 水印图制作页面 Core 选项包含 Core23
- 选择 Core23 + 916尺寸后能正常提交水印制作任务
- 水印底图资源已上传（916尺寸无logo）

### 2.6 需求6：同步状态列表显示C23 + 成品命名规则

FB和TT媒体，C1转为C23的原始素材需要在同步状态列表显示"C23-TT小程序"。
转为C23的素材成品命名需要带上C23和后缀"转Core"。

**命名格式：**
```
{日期}-{语种}-video-{序号}-@{归属人}-C23@{标签}${剧集}${尺寸}$#{素材ID}#转Core.mp4
```

示例：`260328-EN-video-1-@吴昕怡-C23@$二创$前贴$H1一集八集毫不在意长视频-事件一$XYD94$916$#3731822#转Core.mp4`

**验证点：**
- 同步状态列表中 C1→C23 转换的素材显示"C23-TT小程序"
- 转C23后的素材文件名包含"C23"
- 转C23后的素材文件名后缀包含"转Core"
- 转C23后的素材归属人保持为原素材归属人

## 三、数据流

```
素材报表（选择素材 → 转Core素材 → 转为C23素材）
    ↓
同步状态列表（显示 C23-TT小程序 状态）
    ↓
成品素材（命名带C23+转Core后缀，归属人不变）
```

```
视频混剪/原片延长/高光前置（选择Core23 → 配置参数 → 提交）
    ↓
自动化任务列表
    ↓
审核列表
```

```
水印图制作（选择Core23 → 916尺寸 → 提交）
    ↓
制作列表
```
