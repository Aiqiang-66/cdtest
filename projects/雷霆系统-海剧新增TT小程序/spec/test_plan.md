## 2. 产品需求解读

| 维度 | 解读 |
|------|------|
| 业务目标 | 海剧系统新增 Core23（TT小程序）全链路支持 |
| 用户路径 | ① 素材报表→选Core23筛选/转Core23素材 ② 视频混剪→选Core23→生成任务 ③ 烧录资源→落地页/水印选C23 ④ 同步状态列表→查看C23-TT小程序状态 |
| 历史已有逻辑 | Core1/Core4/Core5/Core18 的筛选、转Core、混剪、水印已存在 |
| 本期新增逻辑 | 全模块新增 Core23 选项；转C23素材（FB/TT→TT 916 C23）；水印底图(C23, 916尺寸)；同步状态列表显示 C23-TT小程序；素材命名带 C23+转Core后缀 |
| 本期修改逻辑 | 素材报表 Core选项下拉框、任务列表 Core筛选、投放 Core 增加 Core23；"转Core素材"增加"转为C23素材"；混剪/原片延长/高光前置增加 Core23 |
| 保持不变逻辑 | Core1/4/5/18 的现有功能不变 |
| 待确认逻辑 | Core23 的具体配置参数（集数范围、素材时长限制等）、C23水印底图是否已上传到系统 |

## 4. 测试范围

| 类型 | 范围 |
|------|------|
| 范围内 | 海剧素材报表 Core23 筛选/转Core；视频混剪 Core23；原片延长 Core23；高光前置 Core23；烧录资源-落地页/水印 C23；水印图制作 Core23；同步状态列表 C23-TT小程序；C23素材命名规则 |
| 范围外 | Core1/4/5/18 回归测试（假设无改动）、APP端、非海剧业务 |
| 重点新功能 | FB/TT C1→C23转换规则；C23素材命名+归属人保留；同步状态列表新增C23-TT小程序状态 |
| 重点回归 | Core1/4/5/18 现有功能不受Core23新增影响 |

## 5. 测试策略

| 策略 | 说明 |
|------|------|
| 新功能测试 | 覆盖全部6条需求点的正常流程：Core23选项出现、转C23素材、混剪支持Core23、烧录资源C23、水印制作Core23、同步状态/命名规则 |
| 回归测试 | 验证 Core1/4/5/18 选项仍正常存在；现有转Core功能不变；现有混剪流程不受影响 |
| 边界值测试 | Core下拉框选项数量验证、转换规则边界（FB 45→916→C23）、无C23素材时筛选结果 |
| 异常场景测试 | 无可转C23的素材时点击转Core23、Core23未配置水印底图时提交水印制作 |
| 数据一致性测试 | 转C23后DB素材表Core字段值、归属人不变、命名规则一致 |
| API测试 | Token可用时验证API返回的Core选项列表包含Core23 |
