## 一、需求概述

### 1.1 业务目标

国剧自动化新增两个功能模块：
1. **剧源管理**：上传剧集视频（原片/无字幕+SRT），系统做向量化存储
2. **AI复刻管理**：上传参考视频片段，系统将视频转帧后与剧源做图片匹配，生成无水印复刻视频

### 1.2 核心逻辑

```
剧源管理（上传剧集 → 向量化存储）
         ↓
AI复刻管理（上传参考视频 → 视频转帧 → 图片匹配 → 生成无水印复刻视频）
```

### 1.3 涉及页面

| 页面 | URL |
|------|-----|
| 剧源管理 | `https://sc-test.changdu.ltd/cn-video/source-manage` |
| AI复刻管理 | `https://sc-test.changdu.ltd/cn-video/ai-replica` |

## 四、数据流

```
剧源管理
  ├── 上传原片（有字幕MP4）→ 向量化存储
  └── 上传无字幕（MP4+SRT）→ 向量化存储
         ↓
AI复刻管理
  ├── 上传参考视频（混剪片段MP4）
  ├── 视频转帧 → 图片匹配剧源
  └── 生成无水印复刻视频
         ↓
AsyncJobInfo
  ├── JobType=8（剧源向量处理）
  └── JobType=9（AI复刻）
```

## 七、注意事项

1. **上传等待**：上传剧源和AI复刻的视频需等待上传完成后再点击确定/上传并创建
2. **文件名格式**：原片和无字幕MP4文件名必须为数字+.mp4格式
3. **SRT配对**：无字幕类型每集必须同时包含MP4和SRT文件
4. **环境**：测试需使用dev3环境
5. **向量化**：上传剧源后系统自动进行向量化处理（AsyncJobInfo JobType=8）
6. **复刻匹配**：AI复刻通过视频转帧与剧源图片匹配生成无水印视频（AsyncJobInfo JobType=9）
