## 一、需求概述

### 1.1 业务目标

自动化扩语种功能用于将海剧视频批量扩语种到多个目标语言。用户上传视频后，系统自动识别剧集代号，选择目标语言，生成扩语种任务。

### 1.2 用户路径

```
上传视频 → 系统识别剧集代号 → 选择目标语言 → 确认生成
    ↓
视频生成预览（全选/反选/取消/删除/重新生成）
    ↓
选择媒体 → 确认并上传
```

## 二、功能详情

### 2.1 页面字段

| 序号 | 字段名 | 控件类型 | 必填 | 说明 |
|------|--------|---------|:--:|------|
| 1 | 剧集代号 | 下拉搜索 | ✅ | 上传视频后自动识别填充，disabled状态 |
| 2 | 视频上传 | 拖拽上传 | — | 文件名格式：`代号$语言$二级标签$三级标签$尺寸$`，仅支持 video/mp4 |
| 3 | BGM上传 | 拖拽上传 | — | 仅支持 audio/mp3 |
| 4 | 语言 | 多选Checkbox | ✅ | 欧美/东南亚分组，16种语言可选 |

### 2.3 视频文件名格式

```
代号$语言$二级标签$三级标签$尺寸$.mp4
```

示例：
- `X2035$EN$时尚$热门$916$.mp4`
- `XY14$EN$二及标签$自动化扩语种$916$.mp4`

### 2.4 操作按钮

| 按钮 | 说明 |
|------|------|
| 确认生成 | 提交扩语种任务 |
| 全选 | 全选视频生成预览列表 |
| 反选 | 反选视频生成预览列表 |
| 取消 | 取消选择 |
| 删除所选 | 删除选中的视频 |
| 重新生成 | 重新生成选中的视频 |
| 确认并上传 | 提交上传任务（需先选择媒体） |

### 2.5 媒体选择

| 媒体 | 尺寸 |
|------|------|
| FB | 45/916 |
| TT | 916 |
| UAC | 11/169/916 |

### 2.6 免审核直接上传

开关功能，开启后跳过审核流程直接上传。
