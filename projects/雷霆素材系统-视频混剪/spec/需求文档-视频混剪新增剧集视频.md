## 一、需求概述

### 1.1 业务目标

在雷霆素材系统中新增"视频混剪"功能，支持用户选择剧集代号、配置混剪参数（三级标签、混剪类型、Core、集数范围、素材时长等），一键生成混剪视频任务。任务下发后在自动化任务页面可追踪，审核完成后在审核列表展示。

### 1.2 用户路径

```
视频混剪页面 → 选择剧集代号 → 配置混剪参数 → 确认生成
    ↓
自动化任务页面 → 查看任务详情 → 选择媒体 → 确认并上传
    ↓
审核列表页面 → 审核通过/驳回
```

### 1.3 涉及页面

| 页面 | URL |
|------|-----|
| 视频混剪 | `https://sc-test.changdu.ltd/automation-video/montage` |
| 自动化任务 | `https://sc-test.changdu.ltd/automation-video/montage-task?creatorUid=240017&pageIndex=1&pageSize=30` |
| 审核列表 | `https://sc-test.changdu.ltd/automation-video/montage-audit` |

## 二、功能详情

### 2.1 视频混剪页面

#### 2.1.1 页面字段

| 序号 | 字段名 | 控件类型 | 必填 | 说明 |
|------|--------|---------|:--:|------|
| 1 | 剧集代号 | 输入框 + 下拉检索 | ✅ | 输入关键词检索，下拉展示匹配数据，点击选择 |
| 2 | 三级标签 | 自定义输入框 | — | 用户自由输入 |
| 3 | 混剪类型 | 单选（Radio） | ✅ | 拼接 / 高光前置混剪 / 高光顺拼混剪 |
| 4 | Core | 单选（Radio） | ✅ | Core1 / Core4 / Core5 / Core18 |

#### 2.1.2 Core 差异化配置

**Core1：**

| 字段 | 控件类型 | 说明 |
|------|---------|------|
| 集数范围 | 输入框（开始集数 ~ 结束集数） | 数字输入 |
| 使用剧源的前80%集 | 开关（Switch） | 默认开启，可点击关闭 |
| 素材时长 | 输入框 | 不得低于2分钟，不得高于10分钟 |

**Core4：**

| 集数范围 | 输入框（开始集数 ~ 结束集数） | 数字输入 |
| 使用剧源的前80%集 | 开关（Switch） | 默认开启，可点击关闭 |

## 四、数据流

```
视频混剪页面（确认生成）
    ↓
自动化任务页面（任务列表展示）
    ↓ 点击"查看"
任务详情页面（配置媒体 + 确认并上传）
    ↓
审核列表页面（审核通过/驳回）
    ↓
数据库（BurnResource / BurnResourceTask 等表）
```
