## 一、需求澄清结果

| # | 问题 | 澄清结论 |
|:--:|------|------|
| Q1 | material-report2 与 material-report-applovin 关系？ | **完全独立**，无关联，是单独的报表页面 |
| Q2 | "推广语言剧名(EN-XEY2001)" 格式？ | 通过**代号搜索框**搜索剧代号（如 XEY2001），对该剧进行推广语言维度的数据分析 |
| Q3 | Core下拉范围？ | **全部Core值**可筛选 |
| Q4 | 维度单选/多选/交叉？ | 支持**单选+多选**，支持**维度交叉组合**分析 |
| Q5 | 默认维度/排序/分页？ | **倒序排序**，分页规则，维度根据筛选维度展示 |
| Q6 | 导出表头字段？ | 导出**表头和字段列表**（与页面展示一致） |
| Q7 | 数据源？ | **单数据源**（仅支持一种，非双源切换） |
| Q8 | 业务筛选？ | **三种业务都需要**筛选（海阅/海剧/圣经） |

### 澄清后需求定义

| 需求项 | 明确描述 |
|------|------|
| **页面** | 全新独立页面 `/report/material-report2`，不复用现有Applovin报表 |
| **维度** | 按天统计 / 按7天统计 / 按月统计 / 组长 / 剪辑师 / 投放语言 / 推广语言剧名 / Core(全量) |
| **交互** | 支持维度单选+多选+交叉组合；代号搜索框筛选剧集 |
| **导出** | 导出按钮，导出字段与页面表头+数据一致 |
| **业务** | 海阅 / 海剧 / 圣经 三种业务数据均可筛选 |
| **默认规则** | 倒序排序，标准分页，维度根据所选维度动态展示 |

## 三、数据准确性验证SQL参考

### 3.1 验证按天统计

```sql
-- 验证2026-06-01的APPLOVIN素材数据是否与报表一致
SELECT 
    DATE_FORMAT(stat_date, '%Y-%m-%d') AS day,
    COUNT(DISTINCT asset_id) AS asset_count,
    SUM(spend) AS total_spend,
    SUM(amount) AS total_amount
FROM sharpengine_ads_asset_starrocks.ads_asset_xxx  -- 实际表名待确认
WHERE stat_date BETWEEN '2026-06-01' AND '2026-06-15'
  AND source_chl_type = 'applovin'
GROUP BY day
ORDER BY day DESC;
```

### 3.2 验证Core维度

```sql
-- 验证Core=C1的素材数据
SELECT 
    core,
    COUNT(DISTINCT asset_id) AS cnt,
    SUM(spend) AS spend
FROM material_info  -- 实际表名待确认
WHERE core = 1  -- C1
GROUP BY core;
```

### 3.3 验证推广语言剧名

```sql
-- 验证XEY2001剧集的推广语言数据
SELECT 
    t.tgt_code,
    t.current_language,
    COUNT(DISTINCT a.asset_id) AS cnt,
    SUM(a.spend) AS spend
FROM ads_asset a
JOIN target_code t ON a.tgt_code = t.tgt_code
WHERE t.tgt_code = 'XEY2001'
GROUP BY t.tgt_code, t.current_language;
```
