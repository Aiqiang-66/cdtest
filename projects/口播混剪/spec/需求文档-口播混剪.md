# 口播混剪 UI 需求文档

## 1. 背景
口播混剪功能用于在雷霆素材系统中快速创建口播混剪任务，通过配置剧集、Core类型、口播参数、混剪参数、媒资选择等，生成用于推广投放的视频素材任务。该功能应兼顾任务创建与任务管理两类页面。

## 2. 页面范围
- 口播混剪任务页面（创建/配置任务）
  - URL: `https://sc-test.changdu.ltd/automation-video/oral-montage`
- 自动化任务页面（任务列表与待处理任务）
  - URL: `https://sc-test.changdu.ltd/automation-video/montage-task?creatorUid=240017&pageIndex=1&pageSize=30`
- 审核列表页面（投放/上传审核）
  - URL: `https://sc-test.changdu.ltd/automation-video/montage-audit`

## 3. 口播混剪任务页面功能概述
### 3.1 页面布局
- 页面顶部可能包含环境选择、导航、页面标题等全局元素。
- 任务创建区集中展示表单输入项与生成操作按钮。
- 媒体选择区展示可选媒体列表与批量操作按钮。
- 任务提交区展示“确认生成”、“确认并上传”等动作按钮。

### 3.2 剧集代号选择
- 支持可搜索下拉选择剧集代号。
- 当前页面 DOM 显示为 Ant Design `ant-select` 可搜索选择模式。
- 选择后应联动启用后续“口播集数范围”输入。
- 必选项，未选择时提交应提示校验错误。

### 3.3 三级标签
- 文本输入框，placeholder 为“请输入三级标签”。
- 用于补充任务标签或分类信息，非必填。

### 3.4 Core 选择
- 单选项：Core1 / Core4 / Core5 / Core18。
- 选择 Core 后，口播集数范围组件启用。
- 未选 Core 时，口播集数范围保持禁用。
- 取消 Core 选择后应禁用并清空口播集数范围或恢复默认状态。

### 3.5 口播集数范围
- 包含“开始集数”和“结束集数”两个输入框。
- 仅在 Core 选择后可输入。
- 数值应满足开始集数 <= 结束集数。

### 3.6 口播时长范围
- 包含“最小时长”和“最大时长”。
- 默认值为 30 和 60。
- 用户可根据需求调整区间。
- 数值应满足最小时长 <= 最大时长。

### 3.7 口播音频
- 单选：男声 / 女声。
- 选项决定生成音频的性别音色。
- 默认可选择男声或女声中的一个。

### 3.8 BGM 选择
- 单选：手动选择 / 随机匹配通用。
- 手动选择：后端可按指定逻辑执行 BGM 匹配或允许用户后续选择具体 BGM。
- 随机匹配通用：系统自动匹配背景音乐。

### 3.9 混剪参数
- 包含“混剪集数范围”的开始集数、结束集数输入框。
- 包含“素材时长”的最小时长、最大时长输入框。
- 用于设定混剪素材的选取范围与长度。
- 数值范围应满足合理性校验。

### 3.10 生成数量
- 文本输入框，默认值为 1。
- 用于设置本次任务要生成的视频数量。
- 支持数字输入和边界校验。
- 建议校验上限、非整数、负数、空值等异常输入。

### 3.11 口播文案
- 文案展示区域，支持“生成文案”按钮生成内容。
- 文案结果区域通常为只读文本展示。
- 需要说明是否支持“再次生成”、“复制”、“清空”等操作。
- 按钮点击后，应自动填充文案内容。

### 3.12 媒体选择
- 可选媒体项：
  - FB-45/916
  - TT-916
  - UAC-11/169/916
  - Moloco-916
  - Applovin-916
  - Snapchat-916
- 支持批量操作按钮：全选、反选、取消。
- 需要明确至少选择 1 个媒体才能提交任务（若业务要求如此）。
- 各媒体 checkbox 状态应同步到批量操作按钮。

### 3.13 媒体/内容批量操作
- “全选”：选择所有媒体项。
- “反选”：切换当前媒体选择状态。
- “取消”：清空所有媒体选择。
- “删除所选”：可能用于删除当前选中的媒体或素材项，需确认业务作用对象。
- “重新生成”：可能用于重新生成口播文案或任务内容，需确认触发范围。

### 3.14 免审核直接上传
- 开关控件，用于决定是否绕过审核直接上传。
- 若开启，则任务提交后进入直接上传流程。
- 该开关可能影响“确认并上传”按钮的可用逻辑。

### 3.15 操作按钮
- 生成文案：生成口播文案内容。
- 确认生成：提交当前配置生成混剪任务。
- 确认并上传：在任务已生成且符合上传条件时可用，初始禁用。
- 删除所选：批量删除当前选中媒体/任务项。
- 重新生成：重新执行生成或刷新当前任务内容。
- 全选 / 反选 / 取消：媒体选择批量操作。

## 4. 自动化任务页面功能概述
### 4.1 页面作用
- 展示当前账号创建的自动化任务列表。
- 支持分页、筛选、任务查看与批量操作。

### 4.2 任务列表字段
- 任务名称
- 任务状态
- 创建时间
- CreatorUid
- 任务类型
- 口播参数概览（如 Core、音频、媒体）
- 任务操作列（详情、重新生成、删除等）

### 4.3 任务筛选与分页
- 支持 `creatorUid`、`pageIndex`、`pageSize` 等参数。
- 支持分页展示任务记录。
- 可能支持按状态筛选、按时间排序。

### 4.4 任务操作
- 支持选择任务后执行“删除所选”、“重新生成”等操作。
- 支持查看任务详情、上传状态、审核状态。
- 支持通过任务详情进入审核或上传页面。

## 5. 审核列表页面功能概述
- 展示待审核或已审核任务列表。
- 显示审核状态、审核人、审核时间。
- 支持查看审核详情和审核意见。
- 可能支持“通过”、“驳回”等操作。
- 若免审核直接上传开启，则该任务可能不进入审核列表。

## 6. 交互逻辑与校验规则
### 6.1 必填校验
- 剧集代号必须选择。
- Core 必须选择。
- 生成数量必须输入且为合法数字。
- 口播时长和混剪时长区间应满足最小值 <= 最大值。
- 媒体至少应选择一项（若为业务必需）。

### 6.2 Core 联动
- 选择 Core 后，口播集数范围启用。
- 取消 Core 选择后，口播集数范围禁用并清空。
- 如果页面同时要求先选剧集代号，文案应补充“仅选 Core 可能不足以启用集数范围”。

### 6.3 媒体选择逻辑
- 全选/反选/取消应正确影响所有媒体 checkbox。
- 选中状态与按钮文本应一致。
- 删除所选按钮应只在有选中项时可用。

### 6.4 按钮启用条件
- “确认生成”仅在核心必填项通过校验后可用。
- “生成文案”应在 Core、剧集等必要信息已选择后可用。
- “确认并上传”应在任务生成成功且满足上传条件后可用。

### 6.5 生成数量边界
- 生成数量输入应有合理上限控制。
- 示例：不允许输入超大值、非数字、负数或零。
- 若输入 999，应判断是否属业务允许范围。

### 6.6 口播文案交互
- 生成文案后，文案展示区应显示结果。
- 文案区是否支持复制、编辑、再次生成或清空应在需求中明确。

### 6.7 审核与上传逻辑
- 免审核直接上传开启时，任务可能跳过审核列表。
- 任务提交后应进入自动化任务列表，状态变更可在列表页查看。
- 任务详情页应可查看“是否免审核上传”状态。

## 7. 测试重点
- Core 不同选项对口播集数范围启用和禁用的联动效果。
- 口播音频男/女切换是否正常生效。
- BGM 手动选择与随机匹配切换是否正常。
- 媒体选择全选、反选、取消、删除所选是否正常。
- 生成文案按钮是否能正确生成并展示文案。
- 确认生成后新任务是否出现在自动化任务页面。
- 确认并上传按钮的可用条件与流程是否正确。
- 审核列表页面是否显示任务状态和审核详情。

## 8. 建议验证步骤
1. 使用 VSCode 内置浏览器打开 `https://sc-test.changdu.ltd/automation-video/oral-montage`。
2. 检查页面是否包含环境选择、剧集选择、Core、口播参数、BGM、混剪参数、生成数量、文案区、媒体选择、上传开关和操作按钮。
3. 执行典型配置：选择剧集代号、选 Core、填写时长区间、选音频、选 BGM、选择媒体、点击确认生成。
4. 点击“生成文案”，确认文案内容生成并展示。
5. 执行媒体批量操作：全选、反选、取消、删除所选。
6. 若任务生成成功，打开自动化任务页面 `https://sc-test.changdu.ltd/automation-video/montage-task?creatorUid=240017&pageIndex=1&pageSize=30`，确认新任务是否出现并检查状态。
7. 若适用，打开审核列表 `https://sc-test.changdu.ltd/automation-video/montage-audit`，确认审核流程是否与任务上传状态一致。

## 9. 备注
- 本需求文档基于现有 `口播混剪` 页面结构、DOM 提取和 UI 测试用例分析。
- 若页面后续迭代，需同步更新 Core 类型、媒体列表、按钮文案、校验规则和审核流程。
- 部分按钮作用对象（如“删除所选”“重新生成”）需与产品进一步确认，确保文档精准。
