## 跨业务线搜索

```yaml
# 当需求涉及多个业务线时，合并多个目录ID
# 场景 1: 中台需求影响短剧
  directories: ["87270532", "33292986"]

# 场景 2: 中台的报表需求涉及阅读和短剧
  directories: ["87270532", "2720054", "33292986"]

# 场景 3: 不确定业务线—先问用户
  ⚠️ 不要猜测业务线！必须先询问用户确认
```

## 业务线判断规则

```yaml
判断规则:
  中台:
    - URL 包含 mars-stage/adsweb/admin 等
    - 功能是：权限管理/报表/配置/审批/审核
    - 用户是：管理员/运营/代理商
    - 关键词：广告、投放、ROI、数据源、短剧/国剧/海剧（中台报表类）

  阅读:
    - 功能是：书城/书架/阅读/搜索书籍/章节
    - 用户是：普通读者/C端用户
    - 关键词：书籍、阅读、章节、VIP、充值

  短剧:
    - 功能是：短剧播放/短剧推荐
    - 关键词：短剧、短视频、剧场

  圣经:
    - 关键词：圣经、经文、灵修

  分销:
    - 功能是：分销商管理/分成/结算
    - 关键词：分销、代理、分账

  KOC:
    - 功能是：KOC管理/内容创作者
    - 关键词：KOC、创作者、达人

  不确定:
    - 同时匹配多个业务线 → 询问用户
    - 无法匹配任何业务线 → 询问用户
    - 用户未明确说明 → 根据需求文本推断并询问用户确认
```
