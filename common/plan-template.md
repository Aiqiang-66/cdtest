| 新功能测试 | 覆盖当前新需求新增/修改能力 |

| 兼容性测试 | Web: 分辨率；APP: 平台/版本/Core/语言组合 |
| 海外场景测试 | 覆盖多语言、地区差异、时区、弱网、订阅差异（APP） |
| 异常场景测试 | 弱网/超时/权限/会话过期/状态不满足 |
| 数据状态测试 | 数据一致性/状态流转/DB完整性 |
| API测试 | Token可用时执行接口参数校验和业务规则验证 |
| 审核模式测试（APP/iOS） | iOS审核模式开关、书城/资源位/广告/充值屏蔽策略 |
