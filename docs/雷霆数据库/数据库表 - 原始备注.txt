2.自动化扩语种素材文件字幕必须是英语的，如果是其他语言字幕会导致视频生成完成无字幕的情况，原因在问题2，海剧扩语种，先给大模型英语的srt文件，大模型在去拿英语的文件去做匹配，其他语种的srt文件，然后拿到匹配的srt文件进行烧录到视频上面
传入的字幕文件有3种
ocrSrtFile：ocr文件，这个要英文的
enSrts：原语言文件：这个固定是英文的
langSrts：目标语言文件，比如：西语、印地语……
3.配音剧扩语种，口播视频或高光视频前面几秒是非本剧的视频内容需进行裁剪掉，然后在进行配音扩语种，应配音扩语种找的是首帧，如果首帧不存在传参的剧集里面，
就会出现大模型报错，大模型处理逻辑把视频裁成一帧一帧图片然后去匹配对应剧集数据然后在去合成。字幕是目标剧源自带，音频是根据目标剧源，自动获取。

5.字幕偏差问题排查，先去找到ocrSrtFile的本地srt文件和烧录视频做对比看是否有偏差，如果没有偏差再去找enSrts的英文srt文件和langSrts的本地srt文件做对比看是否有偏差

CREATE TABLE `AsyncJobInfo` (
  `Id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `JobType` int NOT NULL COMMENT '作业类型',
  `DataId` bigint NOT NULL COMMENT '关联数据主键Id',
  `ExtendData` json DEFAULT NULL COMMENT '作业扩展数据',
  `Status` int NOT NULL COMMENT '任务状态|0=已创建,1=执行中,2=成功,3=失败,999=异常',
  `JobId` bigint NOT NULL COMMENT '异步作业ID',
  `JobData` mediumtext DEFAULT NULL COMMENT '异步作业参数',

  `Error` mediumtext DEFAULT NULL COMMENT '错误信息',
  `CreateTime` datetime(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '创建时间',
  `UpdateTime` datetime(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) COMMENT '更新时间',

  PRIMARY KEY (`Id`) /*T![clustered_index] CLUSTERED */,
  KEY `idx_JobType_DataId` (`JobType`,`DataId`),
  KEY `idx_JobId` (`JobId`)
