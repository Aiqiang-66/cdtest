## 🔗 关键关联字段速查

| 关联 | 字段 |
|------|------|
| MaterialInfo ↔ MaterialUploadLog | `MaterialInfo.Id = MaterialUploadLog.MaterialId` |
| MaterialInfo ↔ MaterialBurnJob | `MaterialInfo.Id = MaterialBurnJob.MaterialId` |
| MaterialUploadLog ↔ MaterialSyncTask | `MaterialUploadLog.Id = MaterialSyncTask.SourceUploadLogId` |
| MaterialSyncTask ↔ MaterialSyncSubTask | `MaterialSyncTask.Id = MaterialSyncSubTask.TaskId` |
| AIMixedClipTask ↔ AIMixedClipSubTask | `AIMixedClipTask.Id = AIMixedClipSubTask.TaskId` |
| AutoCreationTask ↔ AutoCreationSubTask | `AutoCreationTask.Id = AutoCreationSubTask.TaskId` |
| AutoCreationTaskMaterial ↔ AsyncJobInfo | `AutoCreationTaskMaterial.Id = AsyncJobInfo.DataId` |
| TaskInfo ↔ sharpengine_ads_global.VideoInfo | `TaskInfo.TgtId = VideoInfo.VideoId` |

## 📊 状态码速查

### AIMixedClipSubTask.Status
| 值 | 含义 |
|----|------|
| 1 | 待处理 |
| 2 | 处理中 |
| 3 | 完成 |
| 4 | 失败 |
| 999 | 已删除 |

### MaterialInfo.MaterialStatus
| 值 | 含义 |
|----|------|
| 9 | 开始烧录 |
| 10 | 烧录完成待审核 |
| 8 | 已完成（最常见） |

### MaterialUploadLog.UploadStatus
| 值 | 含义 |
|----|------|
| 0 | 未上传 |
| 4 | 上传成功 |
