## 四、切句方案说明

| 项目 | 说明 |
|------|------|
| 切句工具 | **pysbd**（Python Sentence Boundary Disambiguation） |
| 支持语言 | en / de / ru / es / fr（葡语降级为 en 模型） |
| 切句方式 | 基于语言规则断句，本地运行，无网络依赖 |
| 选型理由 | 综合最优：分句质量好、速度极快（0.01-0.06s）、无网络依赖、无版本限制 |

### 各语言切句特点

- **英语**：基于英文标点规则断句，语义完整
- **德语/俄语/西语/法语**：使用对应语言模型，按标点+规则断句
- **葡语**：pysbd 不原生支持葡语，降级使用 en 模型，切句效果仍可接受
