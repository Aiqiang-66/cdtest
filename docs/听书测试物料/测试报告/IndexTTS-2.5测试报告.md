# IndexTTS-2.5 测试报告

> **测试日期**：2026年8月24日
> **测试对象**：IndexTTS-2.5
> **测试语言**：英语 / 西语
> **测试章节**：性能覆盖各 20 章；音质/准确率抽查 Ch1、Ch2、Ch3、Ch10、Ch14、Ch17
> **对比模型**：Higgs TTS v3（2026-08-24 现场复测）
> **测试环境**：本地 CPU Whisper（faster-whisper-base，int8）；音频为接口直接调用产物

---

## 一、测试结论 —— 不通过

本次共核验英语、西语各 20 章接口生成结果，其中音质/准确率抽查英/西各 6 章。

1. **接口性能通过**：英/西各 20 章、共 40 章全部合成成功，成功率 100%；整章（约 8000 字符）耗时约 44~54s，常规单集（字符数 300~1400 字符）约 2~9s。
2. **英语不通过**：有爆音，ASR 平均漏词率仅 1.18%，有明显漏读、漏句。
3. **西语不通过**：西语 20 个文件均出现爆音、杂音。
4. **英语和西语漏词需专业人士听测**：目前测试发现有漏词、杂音、爆音等问题，需重点人工复测。

## 五、测试四：与 Higgs TTS v3 性能对比

选取同一本 XR3 第 1 章，对 IndexTTS-2.5 接口与 Higgs TTS v3 的整章响应耗时进行对比。Higgs TTS v3 数据为 2026-08-24 重新下发任务测得，字符数一致。

| 语言 | 字符数 | Higgs TTS v3 | IndexTTS-2.5 | 变化 |
|------|--------|--------------|--------------|------|
| 英语 | 8653 | 104.72s | 54.12s | IndexTTS-2.5 快约 48.3%（约 1.9 倍） |
| 西语 | 8775 | 52.91s | 43.98s | IndexTTS-2.5 快约 16.9%（约 1.2 倍） |

**结论：**

- 英语：54.12s，较 Higgs TTS v3 的 104.72s 快约 48.3%，约 1.9 倍。
- 西语：43.98s，较 Higgs TTS v3 的 52.91s 快约 16.9%，约 1.2 倍。
- **口径说明**：Higgs TTS v3 为 2026-08-24 串行复测，从任务创建到接口返回完成（taskStatus=2）计时；IndexTTS-2.5 为串行口径，从下发到返回音频文件路径计时。

## 六、总体结论

1. **接口性能通过**：40 章成功率 100%，整章 44~54s，常规章 2~9s，西语平均快于英语。
2. **英语不通过**：有爆音，ASR 平均漏词率仅 1.18%，有明显漏读、漏句。
3. **西语不通过**：西语 20 个文件均出现爆音、杂音。
4. **英语和西语漏词需专业人士听测**：目前测试发现有漏词、杂音、爆音等问题，需重点人工复测。
5. **较 Higgs TTS v3 更快**：同章节英语快约 48.3%，西语快约 16.9%。
