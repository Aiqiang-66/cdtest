## 三、自动判定规则（执行器内置）

| 判定 | 触发条件 |
|---|---|
| **PASS** | ① 期望报错的用例（A04a/A04b/A10）确实被拒绝；或 ② 正常用例全部判据通过；或 ③ A01 复现了格式违规退化 |
| **FAIL** | 正常用例出现超长段/高语速段/81.64s 段/`missing_chars`>0/空字幕，或多段落输入却 `paraIndex`≤1；或"应报错"的用例反而成功产出音频 |
| **ERROR** | 任务未成功（超时/失败/metadata 下载失败）——记录 `error` 与 `taskId` |
| **INFO** | 其余异常用例：只记录实际行为（`seg_chars_max`、`n_seg_gt200`、`has_81s_seg` 等），供人工判读 |
